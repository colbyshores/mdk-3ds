2026-11-18  Arena streaming Phase 1a: the level's MTO is no longer resident
==========================================================================

SPEC. docs/ARENA_STREAMING_SPEC.md Phase 1 ("Change Mto to keep only the
directory ... hold a file handle, not the whole file"). EMULATOR and HOST
evidence only: the Old 3DS appliance is pinned to another project (owner,
2026-11-18), so no hardware number is claimed and Phase 1 is not tagged.

1. WHAT CHANGED
---------------
- FileSystem::readRange (3DS romfs/sdmc, Linux posix, test harness) and
  MdkData::readRange: exactly `length` bytes at `offset`, false on a short read.
- Mto::open: reads the 0x18-byte header and the directory only. getArena reads
  that arena's block by range ([offset, offset + size): the size field counts
  itself), parses it at offset 0, frees the block. An unreadable block counts
  as a read failure and fails LevelData::load (as the whole-file read did).
- Arena::parse keeps a copy of the block's MODELS SECTION (models -> next
  section) and rebases every ModelAnimation onto it (ModelAnimation::rebase,
  tracksWithin). That section is the only part of the file anything reads after
  parse (ModelAnimation::bake decodes tracks lazily, from pose_cache). If a
  track fell outside it the whole block is kept; outside even that, the
  animation is dropped and counted (droppedAnimations: zero on every level).
- LevelData::mtoBytes_ removed. All arenas are still parsed at load, so no
  Arena* consumer changed (freeing arenas is Phase 2).

2. THE DEPENDENCY MAP PHASE 2 STARTS FROM (all-resident assumptions)
--------------------------------------------------------------------
Only ModelAnimation borrowed the file (now fixed). Everything below assumes an
arena is parsed for the level's life, and must be handled before arenas are
freed:
- runtime state stored ON the Arena: triangleFlags_ (applyDisabledTriangles,
  setGroupState), groupStates_, groupMaterials_ (script_runtime.cpp
  ~288, ~2079-2128; read by arena_scene.cpp);
- ArenaSpace entries and Bsp (Arena*), bsps_ by name (script_runtime.cpp
  ~274, ~959, ~3016); frontend ArenaSpace (main_3ds.cpp ~795);
- object models/animations straight from arenas: findModel / getAnimation
  store Model* / ModelAnimation* on objects (script_runtime.cpp ~3125, ~3945);
- pose caches keyed by Model* / (Model*, ModelAnimation*) (pose_cache.cpp),
  ObjectView layouts (Model*, Palette*), SurfaceCache (Texture*, Palette*);
- LevelData::palettes_ keyed by Arena*; archivesOf() reads EVERY arena's
  archive (cross-arena materials, level 6 O3_*); arenaNamed linear search;
- debris pieces borrowing an arena's materials vector;
- frontends: LevelView loaded once for the start arena; EffectsView looks and
  objectLooks keep Palette* / TextureArchive* per arena for the level's life.
Full file:line list: the Phase 1a investigation (session transcript); the
entries above are the ones a free/re-parse would break.
