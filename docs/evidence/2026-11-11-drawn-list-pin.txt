  src/Mdk.Game/Collision/ArenaSpace.cs:45-55   SetSolid(IReadOnlyList<string>)

      Named() answers the FIRST arena with that name and null for a name no arena
      has, so an unknown name (including the "" the scripts use for "no arena")

     before it. `move()` already swept element 0 as Kurt's own arena and the rest
     as the free pass (arena_space.cpp:134-146), exactly as the C# does, so no
     other change was needed for a two-name pin to mean what it means there.

  -> mdk_core/src/scripts/script_runtime.{h,cpp}: ScriptRuntime::solidArenas()
     derives that list from currentArena_ / secondArena_ / secondActive_ into a
     member scratch (the C# keeps _solidFirst for the same reason, ":284 kept: no

     the oracle's value, which is the over-generalisation review-3 open question 4
