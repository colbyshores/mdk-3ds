WHAT CHANGED
- Packed originals (romfs:/orig .t3x) are request-then-publish: created as a
  pending id with no I/O; read on the AsyncFileReader worker (new channel
  kChannelOrig; rank-ordered pick Kurt > menu > orig > HD, oldest first; one
  slot kept back for Kurt/menus); imported at the frame boundary after
  C3D_FrameBegin, at most kPackImportsPerFrame; a draw that finds one unmade
  completes it synchronously only AFTER the per-eye frustum cull (before this,
  prepareDraw made every batch's texture before the cull). The .t3x bytes are
  no longer kept on the main heap (a remake re-reads the file). An unreadable
  file falls back to the index texture through mdk_render_texture_needs_pixels.
- Hints (a request no draw made last frame): import only into free linear
  memory above a 1 MiB reserve, never evict, keep an old LRU stamp; answer
  only from the orig pack's name index (no content hash).
- Requests ahead: the arena pump asks for script-hidden batches' packed
  originals; a re-ask pass re-queues evicted ones for the drawn pair; a new
  object warm asks for every object model's packed originals (the arena's own
  models, then every global CMI type), one model a frame, for the pair.
- Menu: mdk_render_update_paletted drops a pending chunked expansion when a
  texture turns streamed (the video/splash pictures).
Reviewed adversarially (independent Opus review, three rounds): H1/H2/N1 and
the W1/W3 findings fixed; final verdicts COMPLETE.
