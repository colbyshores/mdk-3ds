2. F3 (Low, CONFIRMED, FIXED): THE SHAPE ROW MATCHED ONE SPELLING OF A CLASS
--------------------------------------------------------------------------------

The parent row was `grep -c 'grep -[q]'` on the file: it matched the literal
`grep -q` and nothing else, while its own label claimed the class. `grep -Fq`,
`grep -qF`, `grep -qE`, `grep -e x -q` and `grep --quiet` are the same race in
another coat and would have kept the row green.

Now: `EE_PAT='\|[^|]*grep[^|]*-[A-Za-z]*q'` (one alternation covers `-q`, `-Fq`,
`-qF`, `-qE` and `--quiet`), scanned over CODE lines only — this file documents
the rule in prose and a scan that reads its own prose as code can never be
satisfied, which is the same reason `tools/runner/audit_c_with_classes.py`
strips comments before matching. Plus a second row for the other early-exit
consumer, `head`, whose pattern requires the payload to be a variable the shell
already holds, so the twelve `| head -1` uses already in the file are not hits.

NON-VCUITY, BY MUTATION (the only proof a shape row can have):

    inject `printf x | grep -Fq pat`        -> "no code line ... early-exit grep"
                                               reds: expected 0, got 1
    inject `printf y "$SOME_VAR" | head -1` -> the head row reds: expected 0, got 1
    narrow EE_PAT back to one spelling      -> the positive control reds:
                                               expected 5, got 4
    (all three on throwaway copies inside tests/scripts/, so ROOT resolves;
     the copies are deleted, not committed)

Two controls ship with the rows: a positive one that runs the pattern against
all five early-exit spellings and requires 5, and a negative one that requires
`grep -c`, `grep -cE`, `wc -l` and `sort` to stay out. `EmurunHarness` is 253 ->
**257 checks** (+5 rows, -1 row replaced).
