WHAT THE PAIR TESTS. The shader used to compute the MVP product with
`mov r0, inpos`, where `inpos` is a THREE-component float attribute. Every
devkitARM citro3d example forces the fourth component instead ("; Force the w
component of inpos to be 1.0", examples/3ds/graphics/gpu/simple_tri/source/
vshader.v.pica:21-23; same in the vault's
60-references/3ds-platform/citro3d/04-drawing-attributes-vbo.md:197-199), and if
that component came through as 0 the fourth column of the MVP — the translation —
would be multiplied by zero, so the GPU would project the world from the world
origin instead of from the eye. That is a candidate cause for the one-sided view
AND for the other standing mystery (the diagnostic triangle drawn through an
IDENTITY matrix paints nothing, which a w of 0 makes automatic).
