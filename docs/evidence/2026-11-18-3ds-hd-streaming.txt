WHAT LANDED.
  core  ModImages::fromList (the index from a list of files -- the pack's
        manifest -- by the directory scan's own rule) and ModImages::resolve
        (find()'s order, exact key -> level folder -> every level, returning the
        file's PATH, no decode). ColourReplacement::compressedPath; SurfaceCache
        hands it to a new seam, mdk_render_replace_compressed (Linux: no-op; it
        decodes the PC mods). Toggle enableHdTextures (config.ini, 8th menu row).
  3DS   main reads sdmc:/3ds/mdk/hd/manifest.txt, builds the index for the
        level, and wires the lookup into the surface cache. The backend records
        the path per texture; a draw binds the HD copy when it is resident, else
        binds the original and queues it. The frame-boundary pump (after
        C3D_FrameBegin's wait, P3) hands queued paths to an owned reader thread
        (platform/async_file_reader: FZ/DN at entry, 16 KB stack, priority one
        below main, LightLock + LightEvent, joined before C3D_Fini) and imports
        finished buffers (Tex3DS_TextureImport into the linear heap, prebuilt
        chain) at most 2 per frame within a 6 MB budget, evicting the least
        recently drawn copy not drawn last frame. uv goes through the .t3x's own
        texcoord rectangle (Tex3DS_SubTexture), not an assumed orientation. A
        read is handed out only when an import could fit (room for the largest
        pack texture, 512^2 ETC1A4 + chain = 349,504 bytes, or something
        evictable). Animated (stacked-frame) textures keep their original.

REVIEW (independent, same night; libctru 2.7.0 headers and libctru.a symbols
checked: newlib locks are LightLock-backed, devoptab path buffers TLS, so the
worker's stdio on a 16 KB stack is sound). No P3 or threading defect. Fixed:
  F1 an original evicted under memory pressure took its surface with it while
     the HD copy was resident: a resident HD copy now binds whether or not the
     original is, and makeTexture's eviction falls back to an HD copy not drawn
     this frame before an original fails to be made.
  F2 a path >= 192 bytes jammed the queue's head forever: refused when recorded.
  F3 the dispatch gate reserved room for one read while handing out four: it now
     reserves the largest texture per read in flight; a pack built above the 512
     cap (the manifest's column) is refused at load.
  F4 one failed import was permanent: retried after 120 frames, up to 3 times.
  F5 toggle off kept reading and holding up to 6 MB: off now reads nothing and
     frees the resident copies at the frame boundary.
  F6 HD bound on Original-shaded draws of a shared (texture, palette): the bind
     is now Lit/Sprite only, as the PC's replacement is.
  F7 a rotated subtexture is refused; an axis tex3ds padded clamps, not repeats.
  F8 the R1 rationale at the worker's entry, read-back logged.
  F9/F10 comment placement, a redundant clause, over-long manifest lines skipped.
